## What am I looking at?

Shared skills and user instructions for **OpenCode** (primary), Claude Code, and OMP.

## How do I use OpenCode?

Merge this into `~/.config/opencode/opencode.json`:

```json
{
  "instructions": ["https://raw.githubusercontent.com/nori-cloud/agents/main/instructions/AGENTS.md"],
  "skills": ["https://raw.githubusercontent.com/nori-cloud/agents/main/plugins/nori/skills/"]
}
```

Keep dotfile copies until remote loading is verified. See [AGENTS.md](AGENTS.md) for other harnesses and maintenance.
